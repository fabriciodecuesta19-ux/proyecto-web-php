## 📝 Descripción breve del proyecto
Este proyecto es un sitio web dinámico desarrollado en PHP que demuestra la aplicación práctica de los conceptos fundamentales del lenguaje del lado del servidor. El sistema consta de 6 páginas navegables (Inicio, Variables, Condicionales, Bucles, Arreglos y Sesiones) con un diseño unificado mediante CSS externo. Incluye un sistema de control de sesiones que registra la hora de inicio del usuario, calcula su tiempo activo en el sitio y permite reiniciar la sesión. El sistema está publicado en un hosting gratuito y cumple con todos los requisitos de la Unidad 4.

## 💻 Temas PHP implementados
- **Variables y tipos de datos:** Declaración de variables (String, Int, Float, Boolean, Array) y uso de `echo`, `date()` y `count()`.
- **Estructuras de control:** Uso de `if`, `else`, `elseif` y `switch` para la toma de decisiones.
- **Bucles:** Implementación de `for`, `while` y `foreach` para la generación de contenido dinámico (listas y tablas HTML).
- **Arreglos:** Creación y manipulación de arreglos indexados, asociativos y multidimensionales, recorridos con `foreach` y uso de condicionales internos.
- **Sesiones:** Uso de `session_start()`, `$_SESSION` y `session_destroy()` para la persistencia de datos y el cálculo del tiempo activo del usuario.
- **Reutilización de código:** Uso de la función `include()` para el encabezado, menú y pie de página comunes en todo el sitio.
